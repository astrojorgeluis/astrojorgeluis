### 🚀 Main Project — DISCO

> **D**eprojection **I**mage **S**oftware for **C**ircumstellar **O**bjects

An interactive analysis tool for astronomical FITS images of protoplanetary disks. Scientific Python backend (FastAPI + Astropy) with a modern React frontend. Available on PyPI.

```bash
pip install disco-astronomy
disco-start gui
```
